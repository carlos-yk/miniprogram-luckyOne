# 一、项目简介

## 1.1 项目定位

LUCK7 · 今日一注 是一款强调：

* 仪式感
* 幸运感
* 娱乐感
* 社交分享

的「每日随机彩票号码生成小程序」。

核心不是彩票工具，而是：

> “每天抽一次好运”

---

## 1.2 产品理念

区别于传统彩票工具：

* 不做复杂数据分析
* 不做杀号推荐
* 不做专业购彩工具

而是：

✅ 提供沉浸式开奖体验
✅ 提供老虎机式幸运仪式
✅ 提供适合分享的好运结果
✅ 提供年轻化的情绪价值

---

# 十、随机号码生成规则

---

## 双色球规则

### 红球

```text
范围：1~33
数量：6
不可重复
升序排列
```

---

### 蓝球

```text
范围：1~16
数量：1
```

---

## 示例代码

```javascript
function generateSSQ() {

  const reds = [];

  while (reds.length < 6) {

    const n = Math.floor(Math.random() * 33) + 1;

    if (!reds.includes(n)) {
      reds.push(n);
    }
  }

  reds.sort((a, b) => a - b);

  const blue = Math.floor(Math.random() * 16) + 1;

  return {
    reds,
    blue
  };
}
```

# 十七、V1 首页交互确认稿


暂不做：

## 17.2 首页整体结构

首页是产品的核心体验页。

推荐结构：

```text
┌──────────────────────┐
│ 顶部品牌灯牌 / LUCK7 │
```

## 17.4 摇杆交互


交互方式：

* 用户可向下拉动摇杆

不建议：

## 17.8 历史幸运票根区

首页摇号区下方设置历史幸运票根区。

定位：

```text

可回看、可分享的幸运小票
```

展示要求：

* 位于首页首屏内
* 完整展示，不只露出一部分
* 固定高度
* 不制造页面纵向滚动
* 固定展示最近 3 注
* 超过 3 注后，在区块内部上下滚动

历史数量：


滚动方式：

* 最近一次记录优先展示
* 生成一次展示一行
* 超出 3 条后支持上下滚动查看更多历史

* 玩法标签：双色球
* 摇号时间
* 红球号码
* 蓝球号码
* 幸运标签 / 好运短句

## 17.11 视觉与动效重点

优先级最高：

* 机器感
* 摇杆下拉
* 滚轮停止节奏
* 蓝球压轴
* 结果弹窗庆祝感
* 历史票根的好运小票感

动效建议：

```text
摇杆下拉：机械下压 + 回弹
跑马灯：开奖前短暂闪烁
红球：依次停止
蓝球：最后停止并放大/高亮
弹窗：放大弹出 + 光晕 + 粒子/彩带
票根：生成一次新增一行，超过 3 注后区块内上下滚动
```

避免：

* 动效过长导致等待疲劳
* 页面过于卡片化
* 视觉变成普通抽奖工具
* 分享按钮过多
* 历史记录变成普通表格列表
